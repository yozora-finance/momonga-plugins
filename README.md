# モモンガサーチ

モモンガサーチの公式プラグイン配布元です。Codex と Claude で分析コマンドを使えます。通常の ChatGPT はサポート対象外です。

- [導入手順](https://momongasearch.com/user-guide/setup)
- [コマンド一覧](https://momongasearch.com/skills#list)
- [困ったとき](https://momongasearch.com/user-guide/troubleshooting)

スキルはモモンガの `start_command` を呼び、返された分析手順に従います。Claudeと会社のワークスペース配布は、各クライアントのマーケットプレイス同期で更新されます。

Codexでは、Skill使用時にモデルが起動処理を呼びます。導入元はスクリプトが判定し、個人GitHub導入の場合だけ、前回の成功した確認から24時間以上経過していれば配布元のupgradeと検証を行います。個人用は毎回、インストール済みの対象Skill本文から更新指示を取り除いて返します。別の会話が先に更新していても現在の本文を受け取れます。会社などCodex管理配布では更新せず、そのまま分析を始めます。

成功時刻は版番号つきキャッシュの外に保存し、別の会話でも共有します。24時間以内は通信せず、確認に失敗したときは成功時刻を進めません。日付変更ではなく経過24時間で判定します。

権限不足の場合だけ、標準の承認経路で同じ処理を1回再実行します（合計2回まで）。更新できなくても元のSkillの分析手順へ進み、次の利用で更新を再試行します。フックや常駐処理は使いません。個人用はmacOS Desktop同梱のNode/Codexを利用し、Windows個人用は未対応です。

0.3.7以前にはこの使用時更新がないため、初回は一度プラグインを手動更新し、新しい会話で使ってください。
