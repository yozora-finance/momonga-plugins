# モモンガサーチ

モモンガサーチの公式プラグインです。24種類の分析コマンドを、ClaudeとChatGPT・Codexから使えます。

## 導入手順

導入手順、コマンド一覧、困ったときの対処は、モモンガサーチのご利用ガイドをご覧ください。

- [導入手順](https://momongasearch.com/user-guide/setup)（Claude、ChatGPT・Codex、会社の管理者向けを含む）
- [コマンド一覧](https://momongasearch.com/skills#list)
- [困ったとき](https://momongasearch.com/user-guide/troubleshooting)

## このリポジトリについて

ClaudeとChatGPT・Codexのプラグイン配布元です。アプリの画面に `https://github.com/yozora-finance/momonga-plugins` を入力して追加します。
