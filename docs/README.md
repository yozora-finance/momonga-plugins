# モモンガサーチ 接続・利用マニュアル

## 用意するもの

- Claude または ChatGPT のアカウント。Claude のプラグインは有料プラン（Pro・Max・Team・Enterprise）で使えます。ChatGPT はデスクトップ版のアプリが必要です。
- 法人のお試し・有料契約に紐づくモモンガサーチの利用アカウント。

## 接続方法

「モモンガサーチ」は24種の分析コマンドを含む法人向けプラグインです。個人向けリモートMCPは提供していません。

### 導入担当者の案内で各自追加する場合

- [Claude（Web・Desktop）](claude.md)
- [ChatGPT・Codex（デスクトップ）](direct-install.md)

### 会社のワークスペース

- [管理者向け：初回設定](administrators.md)
- [利用者向け：Claude（Web・Desktop）](claude.md)
- [利用者向け：ChatGPT・Codex（デスクトップ）](chatgpt.md)

ログインや接続の許可については、[ログイン・認証の手順](authentication.md)をご覧ください。
