接続には、モモンガサーチの利用アカウントが必要です。まだお持ちでない方は、担当者にお問い合わせください。

プラグインは2種類あります。コマンドを使う方は **「モモンガサーチ＋スキル」** を入れてください。「モモンガサーチ」は検索のみの版です。両方入れる必要はありません。
