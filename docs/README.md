# モモンガサーチ 接続・利用マニュアル

## 用意するもの

- ChatGPT または Claude のアカウント。Claude のプラグインは有料プラン（Pro・Max・Team・Enterprise）で使えます。ChatGPT はデスクトップ版のアプリが必要です。
- モモンガサーチの利用アカウント。

## 接続方法

個人アカウントで利用する場合と、会社のワークスペースで利用する場合で、接続手順が異なります。

### 個人アカウント

- [Claude（Web・Desktop）](claude.md)
- [ChatGPT・Codex（デスクトップ）](personal.md)

### 会社のワークスペース

- [管理者向け：初回設定](administrators.md)
- [利用者向け：Claude（Web・Desktop）](claude.md)
- [利用者向け：ChatGPT・Codex（デスクトップ）](chatgpt.md)

### ログイン・認証

プラグインを追加した後は、自分のモモンガアカウントでログインし、接続を許可します。[ログイン・認証の手順](authentication.md)をご覧ください。

## コマンド一覧

企業調査や比較など、目的に合った分析コマンドを[コマンド一覧](commands.md)から探せます。

## トラブルシューティング

接続できない、コマンドが表示されないなどの場合は、[トラブルシューティング](troubleshooting.md)で症状に合った対処方法を確認してください。
