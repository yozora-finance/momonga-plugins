# モモンガサーチの使い方

会社で導入する方は「管理者の初回設定」から、利用する方はお使いのアプリの「社員向け接続手順」から進めてください。

## 管理者の初回設定

[プラグインの配布・利用許可・更新](administrators.md)

導入先企業のClaude組織、またはChatGPTワークスペースを管理する方が対象です。

## 社員向け接続手順

- [Claude（Web・Desktop）](claude.md)
- [Codex・ChatGPT（デスクトップ）](chatgpt.md)
- [ログイン・認証について](authentication.md)

このリポジトリをChatGPTワークスペースに取り込む方式では、プラグインは **Desktop only** になります。ChatGPT Webでの利用は、この接続手順の対象外です。

接続には、自分のモモンガサーチ利用アカウントが必要です。アカウントがない場合は社内の導入担当者にお問い合わせください。

プラグインは **「モモンガサーチ＋スキル」** を選ぶと、検索と24種の分析コマンドを使えます。「モモンガサーチ」は検索のみの版です。両方入れる必要はありません。

[コマンド一覧](commands.md) ／ [困ったとき](troubleshooting.md) ／ [更新担当者向けの確認メモ](sources.md)
