# 認証を完了して、検索を試す

[ガイドのトップ](README.md)

![モモンガへのログインと初回検索](images/auth-flow.svg)

## 1. 接続を開始する

| アプリ | 開く場所 |
|---|---|
| Claude Web / Desktop | カスタマイズ → プラグイン → モモンガサーチ＋スキル → コネクタ → momonga |
| Codex / ChatGPT Desktop | Plugins → インストール済みのモモンガサーチ＋スキル → 接続設定 |
| ChatGPT のカスタム MCP | 作成したモモンガ接続の Connect／接続 |

**Connect／接続／連携**を押します。インストール時に認証画面が開いた場合は、そのまま次へ進めます。

## 2. 本人のモモンガアカウントでログインする

接続先は `https://mcp.momongasearch.com/mcp`、認証先は **`auth.momongasearch.com`** です。
表示されるログイン方法を選び、**利用権限のある本人のアカウント**でログインします。
利用登録・規約への同意などが表示された場合は、内容を確認して本人が操作してください。

アカウントがない、どのアカウントに利用権限があるか分からない場合は、モモンガの担当者または社内管理者に確認します。
Claude・OpenAI・GitHub のログインとは別の認証です。

## 3. 接続を許可して、アプリに戻る

許可画面が表示されたら、接続するアプリと要求される権限を確認し、接続を許可します。
既に認証・許可済みの場合はログイン画面を経ずに戻る場合があります。
ブラウザが完了を示したら元のアプリに戻り、接続済みの表示またはツールが利用可能になったことを確認します。

![Claudeでの接続完了の例](images/claude-connected.png)

パスワードやトークンをチャットに貼り付ける操作は不要です。
プラグイン経由の接続では、OAuth client ID や API キーを手入力する必要もありません。

## 4. 検索結果まで確認する

新しいチャットでモモンガを選択し、次を送ります。

```text
モモンガサーチを使って、トヨタ自動車（7203）の直近決算を調べて。
対象の決算期、資料名、公表日、出典リンクを付けてください。
```

- モモンガの検索ツールが実行される。
- 企業・対象期間に合う検索結果が返る。
- 資料名・日付・出典リンクがあり、リンクから出典を確認できる。

この3点まで確認できれば利用開始できます。**「インストール済み」だけでは検索の接続確認は完了していません。**
認証エラー・権限エラーが出た場合は[トラブルシューティング](troubleshooting.md)に進んでください。
