# モモンガへのログイン

[使い方のトップ](README.md)

自分のモモンガ利用アカウントで接続してください。

プラグインを入れたら、下記の認証操作でモモンガにログインします。ClaudeやChatGPTへのログインとは別です。

Claudeでは **Chat側の「カスタマイズ」→「コネクタ」→「モモンガサーチ」→「連携させる」** から開きます。
ChatGPTデスクトップのCodexでは、**「設定」→「MCPサーバー」→「momonga」→「認証／Authenticate」** を開いてください。インストールだけではログインは完了しません。

ブラウザに `auth.momongasearch.com` のログイン画面が開きます。利用アカウントでログインし、接続先と権限を確認して許可します。
すでにログイン・許可済みなら、そのままアプリに戻る場合もあります。

アプリに戻ったら、新しいチャットで次を送ってみてください。

```text
モモンガサーチを使って、トヨタ自動車（7203）の直近決算を出典付きで調べて。
```

接続済みでも「利用権限がない」と出る場合は、ログインしたアカウントを確認し、モモンガの担当者へお問い合わせください。
