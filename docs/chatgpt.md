# ChatGPT・Codexでの導入手順

[トップ](../README.md)

ChatGPTまたはCodexのデスクトップアプリで利用します。ChatGPTで利用できるのはデスクトップアプリ版のみです。
個人のアカウントと会社のワークスペースでは設定が分かれているため、利用する側に切り替えて進めてください。ChatGPTを個人のアカウントで使う場合も、モモンガサーチには会社から招待されたアカウントでログインします。

## 1. プラグインを追加する

「Plugins（プラグイン）」を開きます。

- 会社のワークスペースで使う場合：ワークスペース名の一覧に、管理者が配布した「モモンガサーチ」があります。詳細を開き、「＋」を押してインストールします。管理者の設定でインストール済みの場合は、次の手順に進みます。一覧にない場合は、社内管理者に配布予定を確認してください。各自で追加するよう案内された場合は、下の個人のアカウントの手順で追加します。
- 個人のアカウントで使う場合：自分でマーケットプレイスを追加します。
  1. 「プラグイン」→「追加」→「マーケットプレイスを追加」を選びます。
  2. 「ソース（Source）」に `https://github.com/yozora-finance/momonga-plugins`、「Git ref」に `main` を入力し、「スパースパス（Sparse paths）」は空欄のまま「マーケットプレイスを追加」を押します。
  3. 「Personal（個人）」の下に追加されたマーケットプレイスが開きます。「モモンガサーチ」を開いてインストールします。

## 2. モモンガサーチにログインする

インストール後は、ChatGPTへのログインとは別に、モモンガサーチにもログインします。

1. アプリの「設定」→「MCPサーバー」を開き、`momonga` の「認証／Authenticate」を押します。`momonga` が表示されない場合は、アプリを再起動して開き直します。
2. ブラウザに `auth.momongasearch.com` のログイン画面が開きます。招待されたメールアドレスのGoogleアカウントでログインし、接続を許可してアプリに戻ります。すでに許可済みの場合は、ログイン画面を経ずにそのままアプリへ戻ることがあります。

## 3. 動作を確かめる

新しいチャットで `@` を入力してモモンガサーチのプラグインを選び、次のメッセージを送信します。

```text
トヨタ自動車（7203）の直近決算を出典付きで調べて。
```

ツールの使用確認が表示されたら、内容を確認して許可します。出典付きの回答が返ってくれば導入は完了です。

分析コマンドを使う際は、入力欄に `@` を入力して `ファクトシート` などを選び、会社名や条件を続けて入力します。
