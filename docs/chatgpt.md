# 利用者向け：ChatGPT・Codexの接続手順（デスクトップ）

[使い方のトップ](README.md)

管理者が会社のワークスペースにプラグインを配布した後の手順です。導入担当者から案内されたプラグイン名と、モモンガの利用アカウントを用意してください。

## 設定手順

1. デスクトップアプリを開き、会社のワークスペースに切り替えます。
2. 「Plugins（プラグイン）」を開き、会社のワークスペース名の一覧から、案内されたプラグインを探します。
3. プラグインの詳細を開き、「＋」を押してインストールします。
4. 接続を求められたら、そのまま進めます。表示されない場合は、プラグインの詳細から「Connect（接続）」を開きます。
5. 認証画面で自分のモモンガアカウントにログインし、接続を許可してアプリに戻ります。ChatGPTへのログインとは別に必要です。

すでにプラグインがインストールされている場合は、手順4から進めてください。一覧にない場合は、社内管理者に利用できる設定になっているか確認してください。

## 使ってみる

新しいチャットで `@` を打ってモモンガのプラグインを選び、次を送ってください。

```text
トヨタ自動車（7203）の直近決算を出典付きで調べて。
```

ツールの使用確認が出たら、内容を確認して許可します。モモンガで検索され、出典付きの回答が返ることを確認してください。

「モモンガサーチ＋スキル」を利用している場合は、入力欄に `@` を打って `factsheet` などのコマンドを選び、会社名や条件を続けます。

[コマンド一覧](commands.md)

## 更新する

更新の案内を受けたら、新しいチャットを開いて使ってください。内容が変わらない場合は社内管理者に確認します。
