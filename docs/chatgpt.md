# 利用者向け：ChatGPT・Codexの接続手順

[使い方のトップ](README.md)

個人アカウントに追加する方は[個人アカウント向けの追加手順](personal.md)をご覧ください。

以下は管理者が会社のワークスペースにプラグインを配布した後の手順です。自分の会社のワークスペースに切り替え、デスクトップアプリで進めてください。この配布方式では **Desktop only** のため、ChatGPT Webでは使えません。

## 1. プラグインをインストールする

1. **Plugins（プラグイン）** を開きます。
2. **会社のワークスペース名** の一覧で 会社から案内されたプラグインを探します。
3. 詳細を開き、**＋** を押してインストールします。

管理者がインストール済みにしている場合は、そのプラグインを開いて次へ進みます。一覧にない場合は、社内管理者に[初回設定と配布対象](administrators.md)を確認してもらってください。社員がGitHubリポジトリやMCPサーバーを個別に登録する必要はありません。

「Momonga by Yozora Finance」は配布元の名前です。プラグイン名は会社からの案内を確認してください。

## 2. 自分のモモンガアカウントで接続する

インストール中に接続を求められたら、そのまま進めます。求められなかった場合は、プラグインの詳細から **Connect（接続）** を開きます。

ブラウザでモモンガのログイン画面が開いたら、自分の利用アカウントでログインし、接続先と権限を確認して許可します。完了したらアプリへ戻ってください。ChatGPTへのログインとは別に必要です。

[ログインで困った場合](authentication.md)

## 3. 検索して接続を確認する

新しいチャットを開き、入力欄で **`@`** を打ってモモンガのプラグインを選びます。次を送ってください。

```text
トヨタ自動車（7203）の直近決算を出典付きで調べて。
```

ツールの使用確認が出たら内容を確認して許可します。モモンガで検索が実行され、資料の出典付きで結果が返れば接続完了です。ログインが終わっても検索が失敗する場合は、[困ったとき](troubleshooting.md)を確認してください。

## 分析スキルを使う

会社から分析スキル付きの版を案内されている場合に利用できます。

入力欄で **`@`** を打ち、`factsheet` などのスキルを選んで、会社名や条件を送ります。

[24種のコマンド一覧](commands.md)

## 更新を反映する

配布元の更新は管理者が管理します。更新の案内を受けたら、新しいチャットを開いて使ってください。内容が変わらない場合は社内管理者に確認します。

[OpenAI公式：プラグインのインストールと認証](https://learn.chatgpt.com/docs/plugins)
