# ChatGPT・Codexでの導入手順

[トップ](../README.md)

ChatGPT・Codexのデスクトップアプリで使います。ChatGPTのWeb版では使えません。

## 1. プラグインを入れる

会社のワークスペースに切り替え、「Plugins（プラグイン）」でワークスペース名の一覧を開きます。

- 一覧に「モモンガサーチ」がある場合：プラグインの詳細を開き、「＋」を押してインストールします。管理者の設定によっては、すでにインストールされています。
- 一覧にない場合：導入担当者から各自で追加するよう案内されていれば、次の手順で追加します。案内がなければ、社内の管理者に配布の予定を確かめてください。
  1. 「プラグイン」→「追加」→「マーケットプレイスを追加」を選びます。
  2. 「ソース（Source）」に `https://github.com/yozora-finance/momonga-plugins`、「Git ref」に `main` を入力し、「スパースパス（Sparse paths）」は空欄のまま「マーケットプレイスを追加」を押します。
  3. 「Personal（個人）」の下に追加されたマーケットプレイスが開きます。「モモンガサーチ」を開いてインストールします。ここでの「Personal」はアプリ上の追加先の名前で、モモンガサーチの契約は法人契約のまま使えます。

## 2. モモンガサーチにログインする

インストールしただけではログインは済んでいません。ChatGPTへのログインとは別に、モモンガサーチへのログインが必要です。

1. アプリの「設定」→「MCPサーバー」を開き、`momonga` の「認証／Authenticate」を押します。`momonga` が見当たらないときは、アプリを再起動してから開き直します。
2. ブラウザに `auth.momongasearch.com` のログイン画面が開きます。招待されたメールアドレスのGoogleアカウントでログインし、接続を許可してアプリに戻ります。一度許可したあとは、ログイン画面が出ずにそのまま戻ることがあります。

## 3. 動作を確かめる

新しいチャットで `@` を打ってモモンガサーチのプラグインを選び、次を送ります。

```text
トヨタ自動車（7203）の直近決算を出典付きで調べて。
```

ツールの使用確認が出たら、内容を確かめて許可します。出典付きの回答が返れば導入は完了です。

分析コマンドは、入力欄に `@` を打って `ファクトシート` などを選び、会社名や条件を続けて使います。
