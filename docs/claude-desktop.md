# Claude Desktop

[使い方のトップ](README.md)

## プラグインを入れる

Claudeアプリを開き、**「カスタマイズ」→「プラグイン」**を押します。

![Claude Desktopのプラグイン画面](images/claude-plugins.png)

**「＋追加」→「マーケットプレイスを追加」→「リポジトリから追加」**を選び、次のURLを入れて **「同期」**を押します。

```text
https://github.com/yozora-finance/momonga-plugins
```

![URLを入力する画面](images/claude-marketplace.png)

一覧に出てきた **「モモンガサーチ＋スキル」**を追加します。
Webで入れた方は、同じClaudeアカウント・組織で開いているか確認してください。すでに一覧にあれば、次へ進みます。

## モモンガにログインする

プラグインを開き、**「コネクタ」→「momonga」→「接続／連携」**を押します。
ブラウザでモモンガにログインし、接続の許可を済ませたらClaudeアプリに戻ります。

![接続が済んだ状態](images/claude-connected.png)

**「接続済み」**と出ていれば使えます。ブラウザで認証を済ませたのに表示が変わらない場合は、Claudeを終了して起動し直してください。

## 使ってみる

新しいチャットで次を送ります。

```text
モモンガサーチを使って、トヨタ自動車（7203）の直近決算を出典付きで調べて。
```

ツールの使用を確認されたら、内容を見て許可します。出典付きの回答が返ってくることを確かめてください。

コマンドは `/` を打って候補から選びます。

```text
/factsheet トヨタ自動車（7203）
```

[コマンド一覧](commands.md) ／ [更新の方法](claude-web.md#更新する) ／ [困ったとき](troubleshooting.md)
