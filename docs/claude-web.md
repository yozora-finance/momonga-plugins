# Claude Web で接続する

[ガイドのトップ](README.md) · [Desktop の場合](claude-desktop.md)

![Claudeの接続手順](images/claude-flow.svg)

## 1. プラグインを開く

[Claude](https://claude.ai/) にログインし、**カスタマイズ → プラグイン**を開きます。
右上の **＋ 追加 → マーケットプレイスを追加 → リポジトリから追加**を選びます。

![カスタマイズのプラグインタブと右上の追加ボタン（Claude Desktop実画面、Webと共通の設定導線）](images/claude-plugins.png)

画像は同じ設定導線を持つ Claude Desktop で撮影しています。一覧にモモンガがあるのは導入済みの例です。

## 2. リポジトリを登録する

URL 欄に次を入力して、**同期**を押します。

```text
https://github.com/yozora-finance/momonga-plugins
```

![マーケットプレイスのURL欄と同期ボタン](images/claude-marketplace.png)

入力欄がリポジトリ選択になっている場合は、欄を開いて URL または `yozora-finance/momonga-plugins` を入力します。GitHub との接続が求められた場合は画面の案内に従い、対象リポジトリへのアクセスを確認してから Claude に戻ります。組織が登録元を制限している場合は管理者に追加を依頼してください。

## 3. スキル付き版を追加する

同期された一覧から **モモンガサーチ＋スキル**（`momonga-search-skills`）を選び、**追加**します。
プラグインを開き、有効になっていることを確認します。Skills は共通検索1種＋分析24種の **25個**です。

## 4. モモンガにログインする

プラグインの **コネクタ → momonga → 接続／連携**を選びます。
開いた認証画面で、モモンガの利用権限があるアカウントにログインし、表示された権限を確認して許可します。
[認証の共通手順](authentication.md)のとおり Claude に戻り、**接続済み**を確認してください。

![コネクタタブでmomongaが接続済みになった状態](images/claude-connected.png)

## 5. はじめての検索

**新しいチャット**を開き、次を送ります。ツール使用の確認が出たら内容を確認して許可します。

```text
モモンガサーチを使って、トヨタ自動車（7203）の直近決算を出典付きで調べて。
```

モモンガのツールが使われ、資料名・日付・出典リンクを含む結果が返れば検索の接続確認は完了です。
次に `/` を入力し、候補から `factsheet` を選んで「トヨタ自動車（7203）」を続けます。
分析には数分かかることがあります。

[24種のコマンドを試す](commands.md) · [コマンドや結果が出ない場合](troubleshooting.md)

## 更新する

**プラグイン → ＋ 追加 → マーケットプレイスを管理**から対象の同期・更新確認を行い、プラグイン詳細に更新が出たら適用します。その後、新しいチャットを開いてください。
