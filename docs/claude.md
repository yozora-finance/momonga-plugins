# Claudeの接続手順（Web・Desktop）

[使い方のトップ](README.md)

導入担当者から案内されたプラグイン名と、モモンガの利用アカウントを用意してください。

## 設定手順

1. [Claude](https://claude.ai/) またはClaudeアプリにログインし、「設定」から「カスタマイズ」→「プラグイン」を開きます。
2. 右上の「＋追加」→「マーケットプレイスを追加」→「リポジトリから追加」を選び、`https://github.com/yozora-finance/momonga-plugins` を入力します。
3. 「自動的に同期」はデフォルトのオンのままにして、「同期」を押します。
4. 一覧から、導入担当者に案内されたプラグインを開き、右上の「追加」を押します。マーケットプレイスの同期だけでは、プラグインは追加されません。
5. プラグインの「コネクタ」タブを開き、一覧の「momonga」を選びます。接続画面で「接続／連携」を押します。
6. 認証画面が開いたら、自分のモモンガアカウントでログインし、接続を許可します。Claudeに戻り、「接続済み」と表示されれば設定完了です。ログイン・許可済みの場合は、認証画面が省略されることがあります。

すでにプラグインを追加済みの場合は、手順5から進めてください。

## 使ってみる

新しいチャットで、次を送ってください。

```text
モモンガサーチを使って、トヨタ自動車（7203）の直近決算を出典付きで調べて。
```

ツールの使用確認が出たら、内容を確認して許可します。モモンガで検索され、出典付きの回答が返ることを確認してください。

「モモンガサーチ＋スキル」を利用している場合は、入力欄に `/` を打ってコマンドを選び、会社名や条件を続けます。

```text
/factsheet トヨタ自動車（7203）
```

[コマンド一覧](commands.md)

## 更新する

「自動的に同期」をオンにしておくと、公開元の更新が反映されます。プラグインに「更新」が表示されたら押し、新しいチャットを開いてください。
