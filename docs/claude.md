# Claudeの接続手順（Chat・Desktop Code）

[使い方のトップ](README.md)

法人のお試し・有料契約に紐づくモモンガの利用アカウントを用意してください。
プラグインは1つで、24種の分析コマンドを追加します。接続はChat側で登録し、同じアカウント・組織のDesktop Codeと共用します。
個人と会社のワークスペースは接続設定が別です。利用する側を選んでから進めてください。

## 設定手順

1. [claude.ai](https://claude.ai/) またはデスクトップアプリの **Chat側** を開きます。「カスタマイズ」→「プラグイン」→「追加」→「マーケットプレイスを追加」→「リポジトリから追加」で `https://github.com/yozora-finance/momonga-plugins` を入力し、同期します。
2. 「追加」→「マーケットプレイスを管理」で「momonga-plugins」の「…」を開き、「自動的に同期」をオンにします。
3. 「モモンガサーチ」を検索して開き、右上の「追加」を押します。
4. **Chat側の「カスタマイズ」→「コネクタ」→「コネクタを追加」→「カスタムコネクタを追加」** を開き、名前に「モモンガサーチ」、MCPサーバーURLに `https://mcp.momongasearch.com/mcp` を入力します。「続ける」→「今すぐサインイン」・「Claudeの公開アイデンティティを使用」を選び、「追加」を押します。同じ接続先がすでにあれば追加せず、そのコネクタを使います。会社のワークスペースでは管理者が登録し、各利用者はそのコネクタの「連携させる」から進みます。
5. 招待されたメールアドレスのGoogleアカウントでログインし、「接続するアプリ」と「利用する法人」を確認して許可します。利用できる法人がなければ「別のアカウントでログイン」で切り替えます。Chat側で「接続済み」になれば完了です。ログイン・許可済みの場合は認証画面が省略されることがあります。
6. 新しいチャットで「モモンガサーチのファクトシートでトヨタ自動車（7203）を調べて」と送り、ツールの使用を許可します。出典付きのファクトシートが表示されることを確認します。

## Desktop Codeで使う

同じアカウント・組織でCodeを開き、作業フォルダを選んで新しいセッションを開始します。`/` から「ファクトシート」を選び、「トヨタ自動車（7203）」と送ってください。

コマンドが出ない場合は、Code側の「カスタマイズ」→「プラグイン」で「モモンガサーチ」を一度オフにしてからオンにし、新しいセッションを開きます。接続の追加・別の認証・プラグインの再インストールは不要です。

この手順の検証対象はデスクトップアプリ内のCodeです。
