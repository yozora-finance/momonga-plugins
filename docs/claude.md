# Claudeでの導入手順

[トップ](../README.md)

Claudeのデスクトップアプリには「Chat」と「Code」の画面があります。プラグインとコネクタはChatで設定すると、同じアカウント・組織のCodeでもそのまま使えます。個人のアカウントと会社の組織では設定が分かれているため、利用する側でログインして進めてください。

## 1. プラグインを追加する

1. [claude.ai](https://claude.ai/) またはデスクトップアプリのChatで、「カスタマイズ」→「プラグイン」→「追加」→「マーケットプレイスを追加」→「リポジトリから追加」を開きます。
2. `https://github.com/yozora-finance/momonga-plugins` を入力して同期します。
3. 「追加」→「マーケットプレイスを管理」で、追加したマーケットプレイスの「…」を開き、「自動的に同期」をオンにします。新しい版が自動で届くようになります。
4. 「モモンガサーチ」を検索して開き、右上の「追加」を押します。

## 2. モモンガサーチに接続する

Chatの「カスタマイズ」→「コネクタ」を開きます。

- 会社の組織で使う場合：管理者が登録した「モモンガサーチ」のコネクタを開き、「連携させる」を押します。
- 個人のアカウントで使う場合：「コネクタを追加」→「カスタムコネクタを追加」を開き、名前に「モモンガサーチ」、MCPサーバーURLに `https://mcp.momongasearch.com/mcp` を入力します。「続ける」→「今すぐサインイン」と「Claudeの公開アイデンティティを使用」を選び、「追加」を押します。同じURLのコネクタがすでにあれば、そのコネクタの「連携させる」を押します。

ブラウザで `auth.momongasearch.com` のログイン画面が開きます。招待されたメールアドレスのGoogleアカウントでログインし、「接続するアプリ」と「利用する法人」を確認して許可します。利用する法人が表示されない場合は、「別のアカウントでログイン」を選び、招待されたアカウントに切り替えてください。Claudeに戻り、コネクタが「接続済み」と表示されれば接続完了です。一度許可したあとは、ログイン画面を省略してそのままClaudeへ戻ることがあります。

## 3. 動作を確かめる

新しいチャットを開き、次の文を送信してツールの使用を許可します。出典付きのファクトシートが表示されれば導入完了です。

```text
モモンガサーチのファクトシートでトヨタ自動車（7203）を調べて
```

## Codeで使う

Chatと同じアカウント・組織でCodeを開き、作業フォルダを選んで新しいセッションを開始します。入力欄に `/` を入力して「ファクトシート」を選び、「トヨタ自動車（7203）」と続けて送信します。

コマンドが候補に表示されない場合は、Codeの「カスタマイズ」→「プラグイン」で「モモンガサーチ」を一度オフにしてからオンに戻し、新しいセッションを開き直します。コネクタとログイン状態はChatの設定がそのまま引き継がれます。
