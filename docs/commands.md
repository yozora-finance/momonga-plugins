# コマンド一覧

[使い方のトップ](README.md)

「モモンガサーチ＋スキル」で使える24種です。

**Claude**では `/` を打ってコマンドを選び、会社名や条件を続けます。
**ChatGPT・Codex**では `@` から同名のスキルを選び、調べたい内容を送ってください。

たとえば、1社を調べるなら `factsheet`、最近の開示やニュースを見るなら `news-feed` を使います。

## 企業を調べる・比較する

| コマンド | できること | 依頼例（Claude） |
|---|---|---|
| `/factsheet` | 会社の概要と最近の開示・ニュースを1枚にまとめる | `/factsheet トヨタ自動車（7203）` |
| `/comps` | 事業が近い上場企業を探して比較する | `/comps アイフィスジャパン（7833）と事業が近い上場企業` |
| `/longlist` | 指定した条件に合う上場企業を探す | `/longlist 国内で物流倉庫の自動化に取り組む上場企業` |
| `/interview` | 競合との違いと、取材で聞きたいことをまとめる | `/interview アイフィスジャパン（7833）と競合を比較して取材準備` |
| `/news-feed` | 指定した期間の開示・ニュースを一覧にする | `/news-feed トヨタ自動車（7203）、直近3か月` |
| `/yoy` | 2期分の有報を比べ、記載が変わったところを調べる | `/yoy トヨタ自動車（7203）、直近2期の事業等のリスク` |

## 市場・業界・M&Aを調べる

| コマンド | できること | 依頼例（Claude） |
|---|---|---|
| `/industry-map` | 業界の主要企業と企業間の関係を地図にする | `/industry-map 国内の半導体製造装置` |
| `/value-chain` | 取引先や資本・技術提携の関係を調べる | `/value-chain トヨタ自動車（7203）` |
| `/market-size` | 市場規模を見積もるための数字と出典を集める | `/market-size 日本の物流倉庫自動化` |
| `/tamsamsom` | TAM・SAM・SOMを見積もるための資料を集める | `/tamsamsom 日本の物流倉庫向けロボット事業` |
| `/past-acquisitions` | 似た会社・事業の買収事例を、価格や業績とともに調べる | `/past-acquisitions 国内の物流ソフトウェア企業の買収事例` |
| `/buyer-candidates` | 過去の買収事例から、買い手になりそうな企業を探す | `/buyer-candidates 物流倉庫向けソフトウェア事業の売却を想定` |

## 投資・経営課題を比べる

| コマンド | できること | 依頼例（Claude） |
|---|---|---|
| `/growth` | 各社が何に成長投資しているか、金額や目標を比べる | `/growth トヨタ、ホンダ、日産の成長投資` |
| `/capex-plans` | 設備投資計画の金額と完了予定を比べる | `/capex-plans トヨタ、ホンダ、日産の設備新設計画` |
| `/rd` | 研究開発費と研究テーマを比べる | `/rd トヨタ、ホンダ、日産の研究開発` |
| `/human-capital` | 従業員数、平均年収、勤続年数、年齢を比べる | `/human-capital トヨタ、ホンダ、日産の従業員数と平均年収` |
| `/issue-needs` | 各社が挙げる課題を調べる。課題名から企業を探すこともできる | `/issue-needs トヨタ、ホンダ、日産の課題` |
| `/regulation` | 制度変更に対する各社の対応を調べる | `/regulation トヨタ、ホンダ、日産の排ガス規制への対応` |
| `/term-trend` | 特定の用語が有報に登場する頻度を年度ごとに調べる | `/term-trend トヨタ、ホンダ、日産の有報で「生成AI」、直近3期` |

## 根拠を集めて資料にする

| コマンド | できること | 依頼例（Claude） |
|---|---|---|
| `/crosscut` | 同じ質問について複数社の開示を調べ、回答を並べる | `/crosscut トヨタ、ホンダ、日産の電動化方針` |
| `/precedents` | 他社の取り組みと、その後に公表された結果を調べる | `/precedents 上場製造業の生成AI導入とその後の結果` |
| `/evidence` | 主張を裏付ける記述を企業の開示資料から探す | `/evidence 「人手不足が設備投資を促している」、国内物流企業` |
| `/material` | スライド1枚に使う数字・引用・出典と草案を作る | `/material 物流自動化への投資動向を1枚にまとめる材料` |
| `/structure-reference` | 他社の開示資料の見出しや構成を参考にする | `/structure-reference トヨタ、ホンダ、日産の人的資本の開示構成` |

会社名には証券コード、比較には対象年度も添えると伝わりやすくなります。
