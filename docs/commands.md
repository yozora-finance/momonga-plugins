# コマンド一覧

[トップ](../README.md)

モモンガサーチで利用できる24種類のコマンドです（2026年10月21日時点）。

- **ClaudeのCode**：`/` を入力してコマンドを選択し、会社名や条件を続けて入力します。
- **ClaudeのChat**：「モモンガサーチのファクトシートでトヨタ自動車を調べて」のように、コマンド名を含めて依頼します。
- **ChatGPT・Codex**：`@` からコマンドを選択し、会社名や条件を続けて入力します。

## 企業を調べる・比較する

| コマンド | できること | 依頼例（Claude） |
|---|---|---|
| `/ファクトシート` | 企業の基本情報と最近の開示・ニュースを1枚にまとめる | `/ファクトシート トヨタ自動車（7203）` |
| `/コンプス` | 事業内容が近い上場企業を探して比較する | `/コンプス アイフィスジャパン（7833）と事業が近い上場企業` |
| `/ロングリスト` | 指定した条件に合う上場企業を探す | `/ロングリスト 国内で物流倉庫の自動化に取り組む上場企業` |
| `/取材前` | 競合との違いと、取材で確認したい事項をまとめる | `/取材前 アイフィスジャパン（7833）と競合を比較して取材準備` |
| `/新着` | 指定した期間の開示やニュースを一覧にする | `/新着 トヨタ自動車（7203）、直近3か月` |
| `/前期比較` | 2期分の有報を比べ、記載の変更点を調べる | `/前期比較 トヨタ自動車（7203）、直近2期の事業等のリスク` |

## 市場・業界・M&Aを調べる

| コマンド | できること | 依頼例（Claude） |
|---|---|---|
| `/業界地図` | 業界の主要企業と企業間の関係を地図にまとめる | `/業界地図 国内の半導体製造装置` |
| `/バリューチェーン` | 取引先や資本・技術提携の関係を調べる | `/バリューチェーン トヨタ自動車（7203）` |
| `/市場規模` | 市場規模を見積もるための数値と出典を集める | `/市場規模 日本の物流倉庫自動化` |
| `/TAMSAMSOM` | TAM・SAM・SOMを見積もるための資料を集める | `/TAMSAMSOM 日本の物流倉庫向けロボット事業` |
| `/過去買収事例` | 類似する会社や事業の買収事例を、価格や業績とともに調べる | `/過去買収事例 国内の物流ソフトウェア企業の買収事例` |
| `/買手候補` | 過去の買収事例をもとに、買い手候補となる企業を探す | `/買手候補 物流倉庫向けソフトウェア事業の売却を想定` |

## 投資・経営課題を比較する

| コマンド | できること | 依頼例（Claude） |
|---|---|---|
| `/成長戦略` | 各社の成長投資の対象や金額、目標を比較する | `/成長戦略 トヨタ、ホンダ、日産の成長投資` |
| `/設備投資計画` | 設備投資計画の金額と完了予定を比較する | `/設備投資計画 トヨタ、ホンダ、日産の設備新設計画` |
| `/研究開発` | 研究開発費と研究テーマを比較する | `/研究開発 トヨタ、ホンダ、日産の研究開発` |
| `/人的資本` | 従業員数、平均年収、勤続年数、年齢を比較する | `/人的資本 トヨタ、ホンダ、日産の従業員数と平均年収` |
| `/課題ニーズ調査` | 各社が挙げる課題を調べる（課題名から企業を探すことも可能） | `/課題ニーズ調査 トヨタ、ホンダ、日産の課題` |
| `/規制影響` | 制度変更に対する各社の対応を調べる | `/規制影響 トヨタ、ホンダ、日産の排ガス規制への対応` |
| `/用語推移` | 特定の用語が有報に登場する頻度を年度ごとに調べる | `/用語推移 トヨタ、ホンダ、日産の有報で「生成AI」、直近3期` |

## 根拠を集めて資料にする

| コマンド | できること | 依頼例（Claude） |
|---|---|---|
| `/横断` | 同じ質問について複数社の開示を調べ、回答を並べる | `/横断 トヨタ、ホンダ、日産の電動化方針` |
| `/先行事例` | 他社の取り組みと、その後に公表された結果を調べる | `/先行事例 上場製造業の生成AI導入とその後の結果` |
| `/根拠付け` | 主張を裏付ける記述を企業の開示資料から探す | `/根拠付け 「人手不足が設備投資を促している」、国内物流企業` |
| `/素材` | スライド1枚に使う数値・引用・出典と草案を作成する | `/素材 物流自動化への投資動向を1枚にまとめる材料` |
| `/構成の参考` | 他社の開示資料の見出しや構成を参考にする | `/構成の参考 トヨタ、ホンダ、日産の人的資本の開示構成` |
