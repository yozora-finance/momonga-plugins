# コマンド一覧 — 24種

[ガイドのトップ](README.md)

**モモンガサーチ＋スキル**（`momonga-search-skills`）に含まれる分析コマンドです。通常版は自然な言葉で検索できますが、この24種は含みません。

## 使い方

- **Claude Web / Desktop**：`/` を入力し、候補からコマンドを選び、企業名や条件を続けます。
- **Codex / ChatGPT Desktop**：`@` から対応するプラグイン／Skill を選び、表の「依頼例」のコマンド名以降を送ります。

Claude での入力例：

```text
/factsheet トヨタ自動車（7203）
/news-feed アイフィスジャパン（7833）、直近3か月
```

現行パッケージのコマンド名は下記の英語名です。会社名だけでなく、証券コード・対象年度・比較対象を添えると調査範囲が伝わりやすくなります。表の依頼例は入力の例で、調査結果を保証するものではありません。

## 企業を調べる・比較する

| コマンド | できること | 依頼例（Claude） |
|---|---|---|
| `/factsheet` | 1 社の事実を、有報と直近 90 日の開示・ニュースから 1 枚にまとめる | `/factsheet トヨタ自動車（7203）` |
| `/comps` | 対象会社と事業が近い上場企業を、同じ観点・同じ有報で並べる | `/comps アイフィスジャパン（7833）と事業が近い上場企業` |
| `/longlist` | 条件に合う上場企業の候補表を、根拠の原文と出典つきで作る | `/longlist 国内で物流倉庫の自動化に取り組む上場企業` |
| `/interview` | 担当企業と競合を同じ型で並べ、取材で確認する点を付ける | `/interview アイフィスジャパン（7833）と競合を比較して取材準備` |
| `/news-feed` | 企業リストの適時開示・EDINET・ニュース記事を、期間指定か前回確認からの差分で一覧にする | `/news-feed トヨタ自動車（7203）、直近3か月` |
| `/yoy` | 1 社の同じ節を 2 期で比べ、変わった点だけを並べる | `/yoy トヨタ自動車（7203）、直近2期の事業等のリスク` |

## 市場・業界・M&Aを調べる

| コマンド | できること | 依頼例（Claude） |
|---|---|---|
| `/industry-map` | 事業を営む上場企業を、事業系統・該当事業の売上・資本と取引の矢印で四季報型の地図にする | `/industry-map 国内の半導体製造装置` |
| `/value-chain` | 1 社を起点に、相手側と自社の開示から取引先・資本・技術の関係を集め、工程に並べた図と根拠の表にする | `/value-chain トヨタ自動車（7203）` |
| `/market-size` | 事業の市場全体（日本）の規模の材料を、資料に書かれた市場規模・供給側の売上・顧客側の支出の 3 段で並べる | `/market-size 日本の物流倉庫自動化` |
| `/tamsamsom` | 事業の TAM・SAM・SOM の候補を、開示とニュースから出典つきで揃える | `/tamsamsom 日本の物流倉庫向けロボット事業` |
| `/past-acquisitions` | 売り案件に似た会社・事業の買収事例を、取引形態・取得対価・対象会社の業績つきで並べる | `/past-acquisitions 国内の物流ソフトウェア企業の買収事例` |
| `/buyer-candidates` | 売り案件に似た買収事例から、追加の買い手候補と検討根拠を探す | `/buyer-candidates 物流倉庫向けソフトウェア事業の売却を想定` |

## 投資・経営課題を比べる

| コマンド | できること | 依頼例（Claude） |
|---|---|---|
| `/growth` | 企業群の成長投資の方向性を 8 分類で数え、金額・期限・数値目標・適時開示の裏付けで具体性を示す | `/growth トヨタ、ホンダ、日産の成長投資` |
| `/capex-plans` | 設備の新設等の計画の総額・既支払額・残額・完了予定を企業横断で並べる | `/capex-plans トヨタ、ホンダ、日産の設備新設計画` |
| `/rd` | 研究開発費・売上高比率・テーマを企業横断で並べる | `/rd トヨタ、ホンダ、日産の研究開発` |
| `/human-capital` | 従業員数・平均年収・勤続・年齢を、連結／提出会社の範囲を分けて企業横断で並べる | `/human-capital トヨタ、ホンダ、日産の従業員数と平均年収` |
| `/issue-needs` | 企業群の課題を言及社数の順に並べる。引用符つきの課題名なら、それを書いている会社を探す | `/issue-needs トヨタ、ホンダ、日産の課題` |
| `/regulation` | 制度変更への言及と対応を、企業群の有報から期ごとに数える | `/regulation トヨタ、ホンダ、日産の排ガス規制への対応` |
| `/term-trend` | 固定した企業群の有報で、用語を書いた会社の数と初出の年度を年度ごとに数える | `/term-trend トヨタ、ホンダ、日産の有報で「生成AI」、直近3期` |

## 根拠を集めて資料にする

| コマンド | できること | 依頼例（Claude） |
|---|---|---|
| `/crosscut` | 企業リストに同じ問いを当て、観点ごとに要点と原文を並べる | `/crosscut トヨタ、ホンダ、日産の電動化方針` |
| `/precedents` | 取り組みを公表した上場企業と、その後の開示に書かれた結果を出典つきの表にする | `/precedents 上場製造業の生成AI導入とその後の結果` |
| `/evidence` | 主張 1 件（または貼った資料の先頭の 1 文）の根拠を、範囲の企業群の開示から集める | `/evidence 「人手不足が設備投資を促している」、国内物流企業` |
| `/material` | スライド 1 枚分の数値・引用・脚注と、それだけで書いたスライド草案を作る | `/material 物流自動化への投資動向を1枚にまとめる材料` |
| `/structure-reference` | 他社の節構成・言い回し・図表の有無を、転載せずに並べる | `/structure-reference トヨタ、ホンダ、日産の人的資本の開示構成` |

## 検索だけを頼むとき

```text
モモンガサーチを使って、トヨタ自動車（7203）の直近決算を出典付きで調べて。
```

結果に付く資料名・日付・出典を確認してください。対象によって資料が見つからない場合もあります。
専用の表の表示可否はアプリ側の対応によって異なります。
