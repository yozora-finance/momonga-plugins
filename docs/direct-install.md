# 法人利用者向け：ChatGPT・Codexへ直接追加（デスクトップ）

[使い方のトップ](README.md)

法人のお試し・有料契約に紐づくモモンガの利用アカウントを用意してください。

導入担当者から各自追加するよう案内された場合の手順です。アプリ上の「Personal（個人）」は追加先の名称であり、モモンガサーチの個人向け契約を意味しません。

## 設定手順

1. デスクトップアプリを開き、「プラグイン」→「追加」→「マーケットプレイスを追加」を選びます。
2. 「ソース（Source）」に `https://github.com/yozora-finance/momonga-plugins` を入力します。「Git ref」は `main`、「スパースパス（Sparse paths）」は空欄にします。
3. 「マーケットプレイスを追加」を押します。完了すると、Personal（個人）に追加した配布元が開きます。
4. 配布元「モモンガサーチ」の一覧から、「モモンガサーチ」を開き、インストールします。
5. 接続を求められたら、そのまま進めます。表示されない場合は、プラグインの詳細から「Connect（接続）」を開きます。
6. 認証画面で自分のモモンガアカウントにログインし、接続を許可してアプリに戻ります。ログイン・許可済みの場合は、認証画面が省略されることがあります。

すでにプラグインを追加済みの場合は、手順5から進めてください。

## 使ってみる

新しいチャットで `@` を打ってモモンガのプラグインを選び、次を送ってください。

```text
トヨタ自動車（7203）の直近決算を出典付きで調べて。
```

ツールの使用確認が出たら、内容を確認して許可します。モモンガで検索され、出典付きの回答が返ることを確認してください。

分析コマンドを使うには、入力欄に `@` を打って `factsheet` などのコマンドを選び、会社名や条件を続けます。

[コマンド一覧](commands.md)

この手順はアプリの実装をもとに確認しています。Momongaの認証から検索までの実機確認は未完了です。
