# 個人アカウント向け：Codex・ChatGPTデスクトップへの追加

[使い方のトップ](README.md)

公開GitHubリポジトリを、自分のデスクトップアプリのマーケットプレイスとして追加します。利用するプラグインは会社の導入担当者が決めます。案内されたプラグイン名を確認してから進めてください。会社から配布されたプラグインを使う方は、[ワークスペース向けの接続手順](chatgpt.md)へ進んでください。

## 1. マーケットプレイスを追加する

デスクトップの **プラグイン → 追加 → マーケットプレイスを追加** を開きます。

| 欄 | 入力値 |
|---|---|
| ソース（Source） | `https://github.com/yozora-finance/momonga-plugins` |
| Git ref | `main` |
| スパースパス（Sparse paths） | 空欄 |

**マーケットプレイスを追加** を押します。完了すると、Personal（個人）の追加した配布元が開きます。

## 2. プラグインをインストールする

追加した配布元 **Momonga by Yozora Finance** で、会社から案内されたプラグインを開き、インストールします。

## 3. ログインして検索する

接続を求められたら、自分のモモンガアカウントでログインして許可します。表示されない場合はプラグインの接続設定を開いてください。[認証の説明](authentication.md)も参照できます。

新しいチャットで `@` からモモンガを選び、次を送ります。

```text
トヨタ自動車（7203）の直近決算を出典付きで調べて。
```

モモンガで検索が実行され、出典付きの回答が返れば接続完了です。会社から分析スキル付きの版を案内されている場合は、`@` からスキルも選べます。[コマンド一覧](commands.md)

## ChatGPT Webとの違い

この操作はデスクトップのローカル環境への登録です。ChatGPT Webに同じマーケットプレイスが同期される手順ではありません。WebはローカルのCodex設定を読みません。

WebのカスタムMCP追加は別の接続方法で、このGitHubリポジトリの分析スキルをまとめて取り込む操作ではありません。

## 「マーケットプレイスを追加」がない場合

ブラウザではなく、デスクトップのプラグイン画面を開いているか確認してください。下記の確認環境以外ではメニューや利用可否が異なることがあります。会社の環境ではプラグイン機能の利用制限も確認してください。
