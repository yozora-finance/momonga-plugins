# トラブルシューティング

[トップ](../README.md)

| 症状 | 試すこと |
|---|---|
| モモンガが一覧にない | 会社のアカウントやワークスペースで開いているか確認します。ChatGPT・Codexでは、社内管理者にプラグインの取り込み結果と、ご自身の役割への利用許可を確認してもらってください。 |
| リポジトリを追加できない | URLに `https://github.com/yozora-finance/momonga-plugins` を入力します。追加できない場合は、表示されたエラー内容を社内管理者に伝えてください。 |
| コマンドが出ない | 「モモンガサーチ」がインストール・有効化されているか確認し、新しいチャットを開きます。ClaudeのChatでは「モモンガサーチのファクトシートで調べて」と指示し、ClaudeのCodeは `/`、ChatGPT・Codexは `@` から選びます。 |
| モモンガを使わずに答える | プラグインを選び、「モモンガサーチを使って」と指示して送信してください。 |
| 「接続／連携」が押せない | Web版は画面を再読み込みし、Desktopアプリは再起動してから、もう一度プラグインを開いてください。 |
| Codexで認証画面が出ない | 「設定」→「MCPサーバー」の `momonga` から「認証／Authenticate」を押します。 |
| 古い版（0.1.x）が入っている | 0.2.0でプラグインのIDが変わりました。古いプラグインを削除し、導入手順に沿って入れ直してください。 |
| ログイン後に戻らない | ブラウザでの認証操作が終わったら、手動で元のアプリへ戻ります。未接続のままの場合は、ClaudeはChatのコネクタの「連携させる」、ChatGPT・Codexは「設定」→「MCPサーバー」の「認証／Authenticate」からやり直してください。 |
| 認証期限切れ・401 | Codexは「設定」→「MCPサーバー」から再認証します。ClaudeはChatのコネクタから再ログインします。 |
| 利用権限がない・403 | モモンガにログインしたアカウントを確認します。解決しない場合は、モモンガの担当者へお問い合わせください。 |
| 接続済みなのに検索できない | 新しいチャットでモモンガを選び直します。ツール使用の確認が表示されたら応答してください。 |
| 利用制限・429 | 表示された時間をおいて再度試します。繰り返す場合は担当者に確認してください。 |
| 分析が終わらない | 分析には数分かかることがあります。エラーで止まった場合は文面を控え、対象の企業数や期間を絞って試してください。 |
| 検索が0件 | 会社名に証券コードを添え、検索期間を広げて試してください。 |
| ChatGPT Webでスキルが出ない | このリポジトリを組織に取り込む方式はデスクトップアプリ専用（Desktop only）です。デスクトップアプリを開き、[ChatGPT・Codexでの導入手順](chatgpt.md)に沿って進めてください。 |
| Claudeで更新が反映されない | 画面を再読み込みしてプラグインのバージョンを確認します。変わらない場合は、「マーケットプレイスを管理」で「自動的に同期」がオンになっているか確認してください。 |
| ChatGPT・Codexで更新が反映されない | アプリを再起動し、新しいチャットを開きます。会社の一覧から追加した場合は、社内管理者に同期結果を確認してもらってください。 |
| ClaudeのCodeでコマンドが出ない | 作業フォルダを選び、Codeの「カスタマイズ」でプラグインを一度オフにしてからオンに戻し、新しいセッションを開きます。 |
| ClaudeのCodeで検索ツールが使えない | Chatと同じアカウント・組織でログインしているか、またChatのコネクタが接続済みか確認します。個人と会社の設定は別々です。 |

## 認証でエラーが出た場合

`invalid_client` や `redirect_uri` と表示された場合は、利用中のアプリ名とエラー文面を社内管理者またはモモンガの担当者に伝えてください。プラグインのOAuth設定と接続先に登録された戻り先URLの確認が必要です。

## 管理者向け

| 症状 | 確認すること |
|---|---|
| ChatGPTでImport marketplaceが見つからない | ワークスペースの管理者アカウントでログインしているか確認してください。 |
| ChatGPTの取り込み・同期がエラーになる | Import resultsまたは同期結果を確認します。SourceにリポジトリのURLを入力し、Pathは空欄のまま登録します。GitHubの読み取り権限も確認してください。 |
| Claudeの組織向け同期で公開リポジトリを登録できない | 本リポジトリは各社員が自身の **設定 → プラグイン** から追加する構成です。[Claudeでの導入手順](claude.md)に沿って進めてください。 |

## 解決しない場合

利用中のアプリ名、止まった操作、エラー画面、発生日時を、社内管理者またはモモンガの担当者に伝えてください。パスワード、トークン、認証中のURLは除いて送ってください。
