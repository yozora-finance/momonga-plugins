# 困ったとき

[使い方のトップ](README.md)

| 症状 | 試すこと |
|---|---|
| 「Momonga by Yozora Finance」で見つからない | 配布元の名前です。Codex・ChatGPTでは **Plugins → 会社のワークスペース名** で会社から案内されたプラグインを探してください。 |
| モモンガが一覧にない | 会社のアカウント・ワークスペースで開いているか確認します。Codex・ChatGPTでは、管理者に取り込み結果と自分の役割への利用許可を確認してもらってください。 |
| リポジトリを追加できない | URLを `https://github.com/yozora-finance/momonga-plugins` にします。GitHubの承認待ちや組織の制限があれば管理者に確認してください。 |
| コマンドが出ない | 会社から分析スキル付きの版が案内されているか確認してください。案内されている場合は対象プラグインを追加し、新しいチャットを開きます。Claudeは `/`、Codex・ChatGPTは `@` から選びます。 |
| モモンガを使わずに答える | プラグインを選び、「モモンガサーチを使って」と指定してください。 |
| 「接続／連携」が押せない | Webは再読み込み、Desktopは再起動して、もう一度プラグインを開いてください。 |
| ログイン後に戻らない | ブラウザで完了したら元のアプリへ戻ります。未接続のままなら、アプリの「接続」からやり直してください。 |
| 認証期限切れ・401 | プラグインの接続設定から再ログインしてください。 |
| 利用権限がない・403 | モモンガにログインしたアカウントを確認してください。解決しなければモモンガの担当者へお問い合わせください。 |
| 接続済みなのに検索できない | 新しいチャットでモモンガを選び直します。ツール使用の確認が出ていたら応答してください。 |
| 利用制限・429 | 表示された時間を置いて試してください。繰り返す場合は担当者に確認してください。 |
| 分析が終わらない | 数分かかることがあります。エラーで止まった場合は文面を控え、企業数や期間を絞って試してください。 |
| 検索が0件 | 会社名に証券コードを添え、期間を広げて試してください。 |
| ChatGPT Webでスキルが出ない | このリポジトリを組織に取り込む方式はDesktop onlyです。[デスクトップの接続手順](chatgpt.md)を使ってください。 |
| 更新されない | Codex・ChatGPTでは管理者に同期結果を確認してもらい、新しいチャットを開きます。Claudeでは自分が追加したマーケットプレイスの更新を確認してください。 |

## 認証でエラーが出た場合

`invalid_client` や `redirect_uri` と出た場合は、社内管理者またはモモンガの担当者にアプリ名とエラー文を伝えてください。プラグインのOAuth設定と接続先に登録された戻り先URLの確認が必要です。社員がclient IDや認証設定を変更する必要はありません。

## 管理者向け

| 症状 | 確認すること |
|---|---|
| ChatGPTでImport marketplaceが見つからない | ワークスペースの管理者で開いているか確認してください。 |
| ChatGPTの取り込み・同期がエラーになる | Import resultsまたは同期結果を確認します。SourceはリポジトリのURL、Pathは空欄です。GitHubの読み取り権限も確認してください。 |
| Claudeの組織向け同期で公開リポジトリを登録できない | この公開リポジトリは社員の **カスタマイズ → プラグイン** から追加します。[Claudeの接続手順](claude.md)を使ってください。 |

## 解決しない場合

使っているアプリ名、止まった操作、エラーの画面、発生日時を、社内管理者またはモモンガの担当者に送ってください。パスワード・トークン・認証中のURLは送らないでください。
