# トラブルシューティング

[トップ](../README.md)

| 症状 | 試すこと |
|---|---|
| モモンガが一覧にない | 会社のアカウント・ワークスペースで開いているか確認します。ChatGPT・Codexでは、管理者に取り込み結果と自分の役割への利用許可を確認してもらってください。 |
| リポジトリを追加できない | URLを `https://github.com/yozora-finance/momonga-plugins` にします。追加できない場合は、表示されたエラーを社内管理者に伝えてください。 |
| コマンドが出ない | 「モモンガサーチ」がインストール・有効化されているか確認し、新しいチャットを開きます。Claude Chatは「モモンガサーチのファクトシートで調べて」と依頼し、Desktop Codeは `/`、ChatGPT・Codexは `@` から選びます。 |
| モモンガを使わずに答える | プラグインを選び、「モモンガサーチを使って」と指定してください。 |
| 「接続／連携」が押せない | Webは再読み込み、Desktopは再起動して、もう一度プラグインを開いてください。 |
| Codexで認証画面が出ない | 「設定」→「MCPサーバー」の `momonga` から「認証／Authenticate」を押します。 |
| 古い版（0.1.x）が入っている | 0.2.0でプラグインのIDが変わりました。古いプラグインを外し、導入手順に沿って入れ直してください。 |
| ログイン後に戻らない | ブラウザでの操作が終わったら、元のアプリへ戻ります。未接続のままなら、ClaudeはChatのコネクタの「連携させる」、ChatGPT・Codexは「設定」→「MCPサーバー」の「認証／Authenticate」からやり直してください。 |
| 認証期限切れ・401 | Codexは「設定」→「MCPサーバー」から再認証します。ClaudeはChat側のコネクタから再ログインします。 |
| 利用権限がない・403 | モモンガにログインしたアカウントを確認してください。解決しなければモモンガの担当者へお問い合わせください。 |
| 接続済みなのに検索できない | 新しいチャットでモモンガを選び直します。ツール使用の確認が出ていたら応答してください。 |
| 利用制限・429 | 表示された時間を置いて試してください。繰り返す場合は担当者に確認してください。 |
| 分析が終わらない | 数分かかることがあります。エラーで止まった場合は文面を控え、企業数や期間を絞って試してください。 |
| 検索が0件 | 会社名に証券コードを添え、期間を広げて試してください。 |
| ChatGPT Webでスキルが出ない | このリポジトリを組織に取り込む方式はDesktop onlyです。[ChatGPT・Codexでの導入手順](chatgpt.md)を使ってください。 |
| Claudeで更新が反映されない | 画面を再読み込みして、プラグインのバージョンを確認してください。変わらない場合は「マーケットプレイスを管理」で「自動的に同期」がオンか確認します。 |
| ChatGPT・Codexで更新が反映されない | アプリを再起動し、新しいチャットを開いてください。会社の一覧から追加した場合は、社内管理者に同期結果を確認してもらいます。 |
| Claude Desktop Codeでコマンドが出ない | 作業フォルダを選び、Code側のカスタマイズでプラグインをオフ→オンにして新しいセッションを開きます。 |
| Claude Desktop Codeで検索ツールが使えない | Chatと同じアカウント・組織か、Chat側のコネクタが接続済みか確認します。個人と会社の設定は別です。 |

## 認証でエラーが出た場合

`invalid_client` や `redirect_uri` と出た場合は、社内管理者またはモモンガの担当者にアプリ名とエラー文を伝えてください。プラグインのOAuth設定と接続先に登録された戻り先URLの確認が必要です。社員がclient IDや認証設定を変更する必要はありません。

## 管理者向け

| 症状 | 確認すること |
|---|---|
| ChatGPTでImport marketplaceが見つからない | ワークスペースの管理者で開いているか確認してください。 |
| ChatGPTの取り込み・同期がエラーになる | Import resultsまたは同期結果を確認します。SourceはリポジトリのURL、Pathは空欄です。GitHubの読み取り権限も確認してください。 |
| Claudeの組織向け同期で公開リポジトリを登録できない | この公開リポジトリは社員の **カスタマイズ → プラグイン** から追加します。[Claudeでの導入手順](claude.md)を使ってください。 |

## 解決しない場合

使っているアプリ名、止まった操作、エラーの画面、発生日時を、社内管理者またはモモンガの担当者に送ってください。パスワード・トークン・認証中のURLは送らないでください。
