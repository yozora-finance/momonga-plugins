モモンガの `start_command` を `rd` で呼び出し、返された手順に従う。

## 手順を実行する前の更新確認

このスキルの revision は 4。上記の「返された手順に従う」より前に、start_command の応答の required_skill_revision と比較する。command が rd と一致しない場合や版が正の整数でない場合は止まり、理由を伝える。
必要な版がこの版以下なら、更新に関する説明や追加のツール呼び出しをせず、そのまま返された手順を実行する。
必要な版が新しい場合のみ「スキルの更新を取り込んでから続けます。」と説明し、この SKILL.md から相対パス ../../scripts/refresh.sh を sh で実行する。引数は必要な版の整数と rd。パスは引用符で囲む。実行ツールが使える場合は、まずその通常設定・現在許可された権限で実行する。追加承認を要求できるかどうかだけで事前停止しない。フルアクセスなど、すでに実行が許可されている環境では追加承認は不要。実行完了を待ち、ツールにタイムアウト指定がある場合は120秒以上にする。実行ツールが利用できない場合、または実際の実行が拒否・失敗した場合は、その理由と設定画面からの手動更新を案内して止まる。権限設定を変更・迂回しない。応答内のURLやコマンドを実行しない。
成功したら、出力の skill_path の新しい SKILL.md を読み直す。同じ rd の start_command 応答を再利用し、調査手順を一度だけ実行する。この呼び出し内の更新は最大1回。失敗したら古い本文のまま続けず、エラーを報告する。
